IELTS states what the task tests: recognising the main idea of a paragraph and <mark style="background: #FFF3A3A6;">distinguishing main ideas from supporting ones</mark>. There are always more headings than paragraphs.

It also states the distractor mechanism outright — a word from an incorrect answer is planted in the text. So a heading that matches one sentence of a paragraph is usually the trap, not the answer; <mark style="background: #ADCCFFA6;">the heading has to cover the paragraph's whole purpose</mark>. Headings deliberately resemble each other, the main idea is sometimes in the last sentence rather than the first, and heading answers are not guaranteed to run in passage order.

<mark style="background: #FFB8EBA6;">The sequencing advice worth following is to do this question type last</mark>, once the other question types have already walked you through the passage. Answering headings cold means summarising paragraphs you have not understood yet; answering them after means you already know what each paragraph was for. Sources disagree here — IELTS's own teacher article suggests headings first, IELTS Liz says there is no right order — but for a band 8 target the deferral converts the hardest type into the easiest.

There is no penalty for a wrong answer, so leaving any item blank is strictly worse than guessing.
