**BSD** (Berkeley Software Distribution) was created in 1977 at UC Berkeley.

When Unix source code leaked in the 1970s, Berkeley researchers created their own variant that became the first truly open source Unix.

## The context

Bell Labs restricted Unix distribution, making it difficult for researchers to modify.

Berkeley wanted to modify Unix for their research needs.

The leaked Unix source code enabled them to create their own variant.

## Why BSD mattered

**First truly open source Unix variant:**
- Source code publicly available
- Others could modify and redistribute freely
- Community-driven development
- Free to use and modify

**Key releases:**

**4.2BSD (1983)** — added TCP/IP networking stack.

**4.3BSD (1986)** — major improvements and optimizations.

**4.4BSD (1993)** — last pure Berkeley release before fragmentation.

## BSD today

Modern BSD variants descended from original 4.4BSD code:

| Variant | Focus |
|---------|-------|
| FreeBSD | Servers, performance, stability |
| OpenBSD | Security-focused |
| NetBSD | Portability across architectures |

## BSD vs Linux

| | BSD | Linux |
|---|-----|-------|
| **Origin** | Direct Unix descendant (Berkeley) | Unix-inspired (Torvalds) |
| **License** | BSD license (permissive) | GPL (copyleft) |
| **Kernel** | BSD kernel | Linux kernel |
| **POSIX** | POSIX-certified | POSIX-compliant |
| **Use** | Servers, embedded systems | Everywhere (servers, desktops, phones) |

## Impact

BSD proved that open source Unix was viable and sustainable.

The success of BSD inspired Linux development.

Both BSD and Linux exist today because AT&T's proprietary restrictions forced the community to create open alternatives.
