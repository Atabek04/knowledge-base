# Physical Layer encodes bits as electrical optical or radio signals

Physical Layer (Layer 1) converts bits into physical signals for transmission.

**Copper cables (Ethernet):**
- NRZ encoding: high voltage (+5V) = 1, low voltage (0V) = 0
- Manchester encoding for clock synchronization

**Fiber optic:**
- Light pulses: light ON = 1, light OFF = 0
- Uses LED or laser to generate pulses

**Wireless (Wi-Fi, Bluetooth):**
- Radio wave modulation
- Different frequencies and wave patterns represent 0 and 1
