> **Matplotlib** = **MAT**LAB-like **PLOT**ting **LIB**rary.
> Named after MATLAB because it was designed to bring MATLAB's plotting capabilities to Python.

Matplotlib is the foundational plotting [[A Python module is a single file and a package is a folder of modules|package]] in Python.

You give it data, it draws charts — line plots, bar charts, scatter plots, histograms, and more.

---

### Why it matters

Most Python visualization libraries ([[Pandas MOC|Pandas]] `.plot()`, Seaborn) are built **on top of** Matplotlib under the hood.

Learning Matplotlib means you understand what's happening beneath every other plotting tool.
