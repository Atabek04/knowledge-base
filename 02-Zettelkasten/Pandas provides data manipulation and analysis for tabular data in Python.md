Pandas is a Python library designed for working with **structured/tabular data** — think spreadsheets or database tables in code.

## Primary Use Cases

**Data cleaning**: Handle missing values, remove duplicates, fix inconsistencies.

**Data transformation**: Filter rows, group by columns, aggregate values, pivot tables.

**Data analysis**: Calculate statistics, generate summaries, explore patterns.

**File operations**: Read and write CSV, Excel, SQL databases, JSON, Parquet.

**Time series**: Work with date-indexed data, resample frequencies, handle time zones.

## Core Data Structures

Pandas provides two fundamental structures:

**Series**: One-dimensional labeled array (single column).

**DataFrame**: Two-dimensional labeled table (rows and columns).

Both structures use labels (indices) rather than just numeric positions, making data access more intuitive.
