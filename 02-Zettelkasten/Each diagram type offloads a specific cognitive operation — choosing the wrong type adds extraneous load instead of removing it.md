### The principle

Every diagram type is a cognitive tool designed to offload a specific mental operation. Matching diagram type to content type eliminates extraneous load. Mismatch imposes it.

The learner or teacher's task is not "should I use a visual?" but "which specific visual operation does this content require?"

---

### The taxonomy

<mark style="background: yellow">**Concept Map**</mark> — for interconnected, relational knowledge with no single causal direction
- Offloads: searching for and articulating how concepts relate
- Use when: the question is "how do these ideas connect?"
- Avoid: when the learner has no prior knowledge to anchor links; for strictly procedural content
- Key feature: labeled edge propositions — without them it becomes a mind map

<mark style="background: yellow">**Mind Map**</mark> — for divergent ideation and early exploration
- Offloads: working memory during brainstorming; externalizes associations
- Use when: generating material, not organizing it; radial association is sufficient
- Avoid: when you need to communicate *how* things relate; when assessing understanding

<mark style="background: yellow">**Flowchart**</mark> — for decision procedures with branching logic
- Offloads: holding the current step + awareness of possible next steps simultaneously
- Use when: the content has genuine decision points (if/then/else logic)
- Avoid: when there are no real decision points (use a numbered list); for expert audiences (expertise reversal effect)

<mark style="background: yellow">**Comparison Matrix / Table**</mark> — for multi-attribute comparison
- Offloads: serial cross-referencing across prose — replaces inferential search with spatial lookup
- Use when: comparing N items across M shared attributes
- Avoid: when items share no meaningful common attributes; when the argument between items matters more than the attribute values

<mark style="background: yellow">**Causal Loop Diagram (CLD)**</mark> — for systems with feedback
- Offloads: tracing 4+ variable feedback loops in working memory
- Use when: understanding *why* a system behaves counterintuitively; loops and delays are the point
- Avoid: when causality is linear; for experts who already hold the causal model; when the model is unverified

<mark style="background: yellow">**Worked Example Diagram**</mark> — for novice procedural-conceptual learning
- Offloads: figuring out what step to take next (frees working memory for learning *why*)
- Use when: teaching a multi-step process to novices for the first time
- Avoid: for intermediate/advanced learners ([[Expertise reversal effect makes scaffolded instruction counterproductive once learners build sufficient schema|expertise reversal]])

<mark style="background: yellow">**Timeline**</mark> — for chronological or sequential content
- Offloads: mental tracking of temporal order; spatial-temporal metaphor makes sequence perceptually available
- Use when: order matters; when comparing parallel chronologies
- Avoid: for cyclical processes; when causal relationships (not just sequence) are the point

<mark style="background: yellow">**Hierarchy / Tree Diagram**</mark> — for taxonomies and prerequisite structures
- Offloads: inferring abstraction level and dependency from prose description
- Use when: content has strict parent-child or general-to-specific relationships
- Avoid: when items belong to multiple branches; when lateral peer relationships matter

### Cross-cutting principles

1. **Spatial contiguity:** labels must be *inside or adjacent to* the diagram element they describe — not in a separate legend. Meta-analysis effect size for contiguous vs. separated: g = 0.63 (Schneider et al. 2018).

2. **Active generation beats passive viewing:** learners who construct a diagram learn more than learners who study a provided one — the cognitive cost of construction is the learning mechanism. See [[Self-generated diagrams produce better transfer than provided diagrams when used as a generation-then-correction sequence]].

3. **Expertise reversal applies to all types:** diagrams that scaffold novices become redundant overhead for experts. Remove them as competence grows.

4. <mark style="background: pink">**More nodes ≠ better learning.**</mark> Krieglstein et al. (2022): disorientation from over-complex concept maps directly elevates extraneous cognitive load (β = 0.80).
