### What it is

3-Pass Rule is a structured method for working through coding problems that forces active recall instead of passive review.

---
### The Three Passes

**Pass 1 — Attempt**
Set a 30-minute timer.
No looking up solutions, no running tests.
Simulate real interview pressure.

**Pass 2 — Study**
Read the solution after time is up.
Understand *why* it works — the invariant, the data structure choice, the time complexity.
Don't just memorize steps.

**Pass 3 — Reproduce**
Come back days later.
Solve the same problem from scratch, no help.
If stuck, the concept didn't stick — revisit Pass 2.

---
### Why it works

Pass 1 creates cognitive struggle — the brain encodes harder under resistance.
Pass 3 uses [[Spaced repetition forces active recall at increasing intervals to strengthen long-term memory|spaced repetition]] to move the solution from short-term to long-term memory.
Skipping Pass 1 turns practice into reading, not problem-solving.
