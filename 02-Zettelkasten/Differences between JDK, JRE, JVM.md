**JVM (Java Virtual Machine):**

- The runtime engine that executes Java bytecode
- Platform-specific implementation
- Core component that actually runs Java programs

**JRE (Java Runtime Environment):**

- **JVM** + **Standard libraries** (java.lang, java.util, etc.)
- Everything needed to _run_ Java applications
- Does NOT include development tools
- <mark style="background: #ABF7F7A6;">End users typically install JRE</mark>

**JDK (Java Development Kit):**

- **JRE** + **Development tools** (javac compiler, debugger, javadoc, etc.)
- Everything needed to _develop and **run**_ Java applications
- Developers need JDK to write and compile Java code
