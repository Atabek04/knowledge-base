A bit (binary digit) is the smallest unit of information in a computer—a single value that can be either 0 or 1.

A byte is a standardized grouping of 8 bits, making it the smallest addressable unit of memory in most modern computers.

Historical context: early computers had different word sizes (6, 12, 36 bits), but standardization on 8-bit bytes emerged from the IBM System/360 (1964) and became universal by the 1970s. Eight bits was chosen as a compromise: large enough to represent useful character sets (256 distinct values) but small enough to be manufactured and transmitted efficiently.

One byte can represent:
- Numbers from 0 to 255 (in unsigned integer format)
- Numbers from -128 to 127 (in signed integer format)
- A single ASCII text character (letters, digits, punctuation)
- 256 distinct symbols (useful for encoding)

Larger units build on the byte:
- Kilobyte (KB): 1,024 bytes (2^10, not 1,000)
- Megabyte (MB): 1,024 KB = ~1 million bytes
- Gigabyte (GB): 1,024 MB = ~1 billion bytes
- Terabyte (TB): 1,024 GB = ~1 trillion bytes

Bits are the fundamental currency of information theory (Shannon entropy is measured in bits), while bytes are the practical unit of storage and transmission.

Understanding bits and bytes is essential because:
- File sizes are measured in bytes
- Network bandwidth is measured in bits per second (Mbps, Gbps)
- Memory addressing works with byte granularity
- Character encoding assigns specific byte values to letters and symbols
