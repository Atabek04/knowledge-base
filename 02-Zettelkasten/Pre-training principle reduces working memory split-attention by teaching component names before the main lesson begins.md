### What it is

Mayer's <mark style="background: yellow">Pre-Training Principle</mark>: people learn more deeply from a multimedia lesson when they know the names and characteristics of the main components before the lesson begins.

If learners must simultaneously learn *what a term means* and *how it behaves* in the main explanation, both demands compete in working memory. Pre-training separates them — the label-to-concept mapping is consolidated in long-term memory first, so it is retrieved (not constructed) when encountered during instruction.

---

### When it matters most

Pre-training has the largest effect when:
- Material is complex and fast-paced
- Components are unfamiliar — novel terminology, new symbol systems, new notation
- The main lesson requires tracking multiple interacting components simultaneously

It is least necessary when components are already familiar — for those learners, pre-training wastes time without adding value.

This creates an interaction with the [[Expertise reversal effect makes scaffolded instruction counterproductive once learners build sufficient schema|expertise reversal effect]]: pre-training benefits novices and is redundant or costly for experienced learners who already know the terms.

---

### Format

A pre-training segment should be brief — 60 to 90 seconds — and cover only the *names and definitions* of components that will appear in the worked example or lesson.

Not the relationships between components. Not how they're used in practice. Just: "Component X means Y."

**Example:** Before explaining a verb conjugation system, a 90-second segment defines three terms on screen — root, pattern, derived form — each with one illustrating example. The main lesson can then use these terms without stopping to define them mid-explanation.

---

### Relation to advance organizers

Pre-training and [[Advance organizers give learners a cognitive hook before new content arrives|advance organizers]] both prepare learners before new content arrives. The distinction: advance organizers build a *conceptual framework* (the big picture); pre-training establishes *component labels* (the vocabulary of the upcoming explanation). Both are useful; neither substitutes for the other.
