### Generation

A keystream is a sequence of pseudo-random bytes generated by encrypting sequential counter values.
In CTR mode, the block cipher encrypts `nonce||1`, `nonce||2`, `nonce||3`, etc., to produce keystream blocks.

Each keystream block has the same size as the cipher's block size.
For AES-128, each keystream block is 128 bits (16 bytes).

### Usage

The keystream is combined with plaintext using XOR to produce ciphertext.
`Ciphertext[i] = Plaintext[i] XOR Keystream[i]`.

### Parallelization

Because keystream generation only depends on the counter values and key, it can be computed independently.
This enables parallel encryption — generate all keystream blocks simultaneously, then XOR with plaintext.

### Uniqueness Requirement

The nonce must be unique for every message encrypted with the same key.
If you reuse a nonce, you generate the same keystream, which catastrophically breaks security.

### Properties

The keystream appears random to anyone without the key.
It passes statistical randomness tests even though it's deterministically generated.

Decryption uses the identical keystream.
Generate the same keystream blocks from the same counter values, then XOR with ciphertext to recover plaintext.

### Security Warning

Never reuse any part of a keystream for different messages.
This is equivalent to using the same one-time pad twice, which completely breaks encryption.
