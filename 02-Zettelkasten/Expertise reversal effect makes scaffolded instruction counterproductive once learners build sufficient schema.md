### What it is

The <mark style="background: yellow">expertise reversal effect</mark> (Kalyuga, Ayres, Chandler & Sweller, 2003) is one of the strongest documented limitations of scaffolded instruction.

As a learner's expertise grows, worked examples, step-by-step guides, and instructional hints that were previously essential become redundant — and then *actively harmful*. The learner's long-term memory now contains rich enough schemas that the scaffold must be read and mentally skipped. That processing costs more working memory than the scaffold saves.

---

### The mechanism

For a novice, a worked example provides the cognitive path that working memory cannot construct independently. For an intermediate learner, that path already exists in long-term memory as a compiled schema. The worked example now forces the learner to process *two representations* of the same thing — the internal schema and the external scaffold — and reconcile them.

This adds extraneous load without contributing germane load. In documented cases, the scaffolded group *underperformed* the problem-solving group.

---

### Evidence

The reversal has been documented across mathematics, English writing instruction, physics, programming, and grammar learning. It is not an artifact of one domain — it is a general feature of how schemas interact with external guidance.

---

### Signals that the reversal point has been reached

<mark style="background: pink">Instructional techniques optimal for novices can harm intermediate learners if retained too long.</mark>

Signs to watch for:
- Learner produces correct examples without consulting the scaffold
- Learner expresses impatience with step-by-step guidance
- Learner skips to the problem without reading the worked example

When these appear: remove the scaffold, increase problem complexity, and shift to open practice. Reintroduce worked examples only if error rates rise again at a harder level.

---

### Relation to adaptive fading

The expertise reversal effect is the *reason* [[Backward fading removes final worked example steps first to preserve context while building independent problem-solving skill|backward fading]] must eventually reach complete removal of scaffold. Fading is not optional — it is required for continued growth.
