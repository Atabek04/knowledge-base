### What it is

Cognitive load theory (Sweller, 1988) states that human working memory holds roughly 4–7 chunks simultaneously.

Learning fails not because content is hard, but because instruction forces working memory to spend capacity on the *wrong* things.

The designer's job: direct limited working memory toward actual schema construction, not navigating poor presentation.

---

### The two load types (updated 2010 model)

<mark style="background: yellow">**Intrinsic load**</mark> — the inherent complexity of the material; the number of interacting elements.
Cannot be eliminated. Managed by sequencing (teach parts before wholes) and activating prior knowledge to compress chunks into schemas.

<mark style="background: yellow">**Extraneous load**</mark> — how the information is *presented*: poor layout, irrelevant details, split-attention effects, redundancy.
Must be minimized. This is the primary target of instructional design.

<mark style="background: cyan">**Note on germane load**:</mark> Pre-2010 CLT listed germane as a third type. The 2010 revision dropped it. Germane processing is now understood as working memory being *redirected* from extraneous to intrinsic work — not a separate bucket to fill.

---

### Key effects and their fixes

| Effect | Problem | Fix |
|---|---|---|
| Split-attention | Diagram and text physically separated | Integrate labels directly onto diagram |
| Redundancy | Same information in audio *and* text simultaneously | Use one modality at a time |
| Expertise reversal | Worked examples are too easy for experts | Switch to problem-solving as competence grows |
| Element interactivity | Too many interacting parts at once | Teach sub-skills in isolation before combining |

---

### Application to sequencing

- Activate prior knowledge first — existing schemas compress new info into fewer chunks
- Teach isolated sub-tasks before combining them
- Use worked examples early; fade to problem-solving as expertise grows
- Eliminate all presentation noise before worrying about content difficulty
