In 1991, Linus Torvalds was a student at University of Helsinki using **Minix**, a small Unix-like teaching operating system.

Frustrated with Minix's limitations, he created Linux as a hobby project to understand kernel internals.

## The Minix problem

**Proprietary** — source code was restricted and couldn't be modified.

**Designed for teaching** — not production-ready for real-world use.

**Slow** — couldn't use advanced 386 processor features.

**Limited features** — missing modern capabilities that Linus wanted.

## Why Linus created Linux

**Frustration** — wanted to modify his OS but couldn't with proprietary Minix.

**Learning** — hobby project to understand kernel internals deeply.

**Freedom** — wanted a free, open-source Unix-like operating system.

**Performance** — designed specifically for 386 architecture to leverage modern hardware.

**Famous quote:** "Just for fun" (from his autobiography).

## The key decision: open source

Unlike proprietary operating systems, Linus released Linux source code publicly on the internet in 1991.

**Result:** Community contributed fixes, features, and optimizations leading to exponential growth.

## Why Linux succeeded

| Factor | Impact |
|--------|--------|
| **Open source** | Community-driven development |
| **Free** | No licensing costs |
| **Unix-like** | POSIX compatible, familiar to developers |
| **Timing** | Internet growing, easy distribution |
| **Good design** | Stable, performant kernel |

Minix was too restrictive → Linus created Linux → released it open source → became dominant OS kernel.
