Above roughly band 6.5 the blocker is not strategy — every course teaches the same essay skeleton, and a candidate at 7 already owns it. The blocker is Task Response depth and lexical precision, and <mark style="background: #FFF3A3A6;">neither is visible from the inside</mark>. You cannot see your own error density; that is what the external rater is for.

Two constraints on how the feedback is used.

<mark style="background: #ADCCFFA6;">An unrewritten marked essay changes nothing.</mark> The correction has to be re-executed on the same prompt before the habit moves, so the unit of work is essay plus rewrite, not essay.

<mark style="background: #FFB8EBA6;">A single marked essay is noise, not signal.</mark> Marker disagreement is documented and large — one vendor's own reviewers report the same script scored 8.5 by one teacher and 6.5 by another, and a marking service produced a three-band gap against a real sitting taken within a day. Use two different markers so systematic bias shows up as a difference rather than hiding as a number.

The volume that follows: roughly 8-12 marked-and-rewritten essays across a five-month plan. Below about six the pattern is unreadable; above twelve it repeats.
