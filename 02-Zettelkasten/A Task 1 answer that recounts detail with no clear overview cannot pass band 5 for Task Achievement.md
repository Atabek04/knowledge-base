Academic Writing Task 1 has one hard gate written directly into the public descriptor, and it is the only place in the Writing rubric where a single missing element is named as the thing that defines a band.

Band 5 Task Achievement, Academic: <mark style="background: #FFB8EBA6;">recounts detail mechanically with no clear overview</mark>. Band 6 is the first band that requires an overview at all — an overview with information appropriately selected. Band 7 sharpens it to a clear overview of main trends, differences or stages.

So a fluent, accurate, well-organised Task 1 answer that walks through every data point without ever standing back is capped at 5 on this criterion, and that is a quarter of the Task 1 mark.

The overview is not a conclusion, and Task 1 takes no conclusion. A conclusion restates points already made, which is wasted words in a 150-word report — teachers are consistent on this, and the descriptor never asks for one.

Band 8 asks that key features be <mark style="background: #ADCCFFA6;">presented, highlighted and illustrated</mark> clearly and appropriately, against band 7's "clearly presents and highlights key features but could be more fully extended" — so the 7 → 8 move is about which figures you choose to cite and what you compare them against, not about more figures.
