# Home router combines router switch and wireless access point

ISPs provide a single physical box that acts as multiple devices:

- **Router**: connects your LAN to the internet (Layer 3)
- **Switch**: connects multiple LAN devices, forwards using MAC (Layer 2)
- **Wi-Fi Access Point**: provides wireless connectivity

This is why you can plug in multiple ethernet cables AND use Wi-Fi from one device.
