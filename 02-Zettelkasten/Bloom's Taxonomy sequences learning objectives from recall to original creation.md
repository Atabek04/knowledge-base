### What it is

Bloom's Taxonomy (revised, Anderson & Krathwohl 2001) is a six-level hierarchy of cognitive operations used to write learning objectives, design assessments, and sequence instruction.

The key revision from the 1956 original: all levels became **action verbs** (not nouns), and "Synthesis" was replaced by "Create" at the apex — producing original work requires evaluative judgment, making it cognitively harder than Evaluate alone.

---

### The 6 levels

| Level | What the learner does | Key verbs |
|---|---|---|
| **Remember** | Retrieve from memory | Define, list, recall, identify, label |
| **Understand** | Construct meaning | Explain, paraphrase, summarize, classify, compare |
| **Apply** | Use a procedure | Apply, solve, demonstrate, predict, execute |
| **Analyze** | Break into parts, find relationships | Analyze, deconstruct, infer, differentiate, contrast |
| **Evaluate** | Judge against criteria | Critique, justify, appraise, evaluate, judge |
| **Create** | Produce something new | Design, generate, construct, devise, compile |

Higher levels require mastery of lower ones — they are prerequisites, not upgrades.

---

### How to use for lesson planning

Write learning objectives as: **"Students will be able to [verb] [content]"** — the verb signals the cognitive level.

- New content: start at Remember/Understand ("list", "explain")
- Growing confidence: shift to Apply/Analyze ("solve", "compare")
- Unit culmination: target Evaluate/Create ("critique", "design")

<mark style="background: pink">Common mistake:</mark> treating lower levels as inferior. They are prerequisites. A Create objective with no Remember foundation produces guesswork, not creation.

---

### Application to assessment design

Use multiple levels within a single unit test:

- Know terminology → Remember
- Explain a concept → Understand
- Solve a problem → Apply
- Find the bug in this code → Analyze
- Defend a design decision → Evaluate
- Build a small system → Create

Combined with [[Backward Design starts from desired outcomes before planning instruction or activities|Backward Design]]: write the Create/Evaluate assessment first, then build instruction that scaffolds up from Remember.

---

### Online vs offline

**Offline:** Use lower levels in early lessons; upper levels for final assessments. Visual Bloom's pyramid on the board helps students understand why exercises progress in difficulty.

**Online:** Frame discussion prompts at Analyze/Evaluate ("compare X and Y, justify your preference"). Peer review for Create-level work.
