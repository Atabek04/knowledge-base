
## Building DSA mindset

DSA is not about cramming for a test.

#### Think in patterns, not problems.

Stop solving problems one by one.
Start recognizing recurring patterns:
- sliding windows
- two pointers
- recursion
- memorization, etc.

#### Embrace failure as part of the process

You will get stuck.
You will feel dumb.
Every problem is a brain upgrade.

#### Focus on understanding, not just passing

If you can't explain why a solution works,
revisit it until you can.

## Follow the 3-Pass Rule

##### First pass
- Set a 30-minute timer for each problem
- Don't look up the solution or press the "run tests" button before then. 
- Create the real interview environment
- No pain, no gain.

##### Second pass
- Read the solution
- ***understand it deeply***
- don't just memorize

##### Third pass
- Other days, solve it from scratch
- Do it without any help
- Check if it stuck or not
- Follow Spaced Repetition Systems
