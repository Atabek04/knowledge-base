
1. <mark style="background: #FFB86CA6;">Non-static fields</mark>

	- also called **instance variables**
	- variables that belong to an **object**
	- objects keep their internal states in non-static fields
	
2. <mark style="background: #FFB86CA6;">Static fields</mark>

	- variables that belong to a **class**
	- static field has the **same value for all objects**
	
3. <mark style="background: #FFB86CA6;">Local variables</mark>

	- variables declared inside a method
	- local variables, only accessible inside the same method that declared it

4. <mark style="background: #FFB86CA6;">Parameters</mark>

	- variables that are passed to a method :luc_arrow_right_circle: when the method is called
	- Parameters also, like local vars, only accessible inside the method that declares them.
		- Although a value is assigned to them when the method is called
