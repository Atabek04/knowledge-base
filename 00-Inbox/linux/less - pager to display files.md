
Pager - displays file content one screen at a time.

#### Why?

- View large files without dumping entire content (memory efficient)
- Navigate: scroll up/down, search, jump to lines
- Better than `cat` for big files

#### Usage

```bash
less file.txt
```

#### Navigation

- `Space`/`Page Down` — next page
- `b` *(back)*/`Page Up` — previous page
- /pattern — search
- `G` — end of file
- `g` — start of file
- `q` — quit
