### Vim has 6 primary modes:

  1. <mark style="background: #BBFABBA6;">Normal Mode</mark> - Default mode for navigation and commands (press Esc)
  
  2. <mark style="background: #BBFABBA6;">Insert Mode</mark> - Text entry (i, a, o, etc.)
  
  3. <mark style="background: #BBFABBA6;">Visual Mode</mark> - Text selection (v, V, Ctrl+v)
  
  4. <mark style="background: #BBFABBA6;">Command-line Mode</mark> - Execute commands (:, /, ?)
  
  5. <mark style="background: #BBFABBA6;">Replace Mode</mark> - Overwrite text (R)
  
  6. <mark style="background: #BBFABBA6;">Select Mode</mark> - Similar to visual but typing replaces selection
