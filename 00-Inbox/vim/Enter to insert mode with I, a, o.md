
All these letters enter you to Insert mode
However they have different behavior.

---

### Insert positions

| Key | Where it inserts   | Mnemonic  |
| --- | ------------------ | --------- |
| i   | Before cursor      | insert    |
| a   | After cursor       | append    |
| o   | New line **below** | open line |
### Uppercase versions

| Key | Where it inserts   |
| --- | ------------------ |
| I   | start of line      |
| A   | end of line        |
| O   | new line **above** |
