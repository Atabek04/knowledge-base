Concepts for understanding Public Key Infrastructure, certificate authorities, X.509 certificate structure, and trust systems.
Covers PKI fundamentals, CA hierarchy, trust chains, certificate structure, Distinguished Names, GOST algorithms, and revocation mechanisms.

## PKI Fundamentals

- [[PKI solves trust problem by introducing trusted third party|PKI solves trust via a trusted third party]]
- [[Certificate binds public key to verified identity|Certificate binds a public key to an identity]]
- [[CA verifies identity before issuing certificates|CA verifies identity before issuing]]
- [[Trust chain transfers trust from pre-installed root to end certificate|Trust chain: root → end certificate]]

## Certificate Authorities

### CA Types & Hierarchy

- [[Root CA is ultimate trust anchor with self-signed certificate|Root CA: self-signed trust anchor]]
- [[Intermediate CA performs daily certificate signing operations|Intermediate CA signs day-to-day certs]]
- [[RA verifies identity at public-facing offices|RA verifies identity in person]]

### Security Infrastructure

- [[HSM protects private keys with tamper-resistant hardware|HSM guards private keys in tamper-resistant hardware]]

## Trust Chain & Verification

- [[Transitive trust flows from root through intermediates to end certificate|Transitive trust: root → intermediates → end]]
- [[Root certificate is pre-installed in operating system trust store|Root cert ships in the OS trust store]]
- [[Certificate chain includes end certificate plus all intermediates|Cert chain = end cert + intermediates]]
- [[Trust store contains database of trusted root certificates|Trust store = trusted root certs DB]]
- [[Browser builds chain from server certificate to trusted root|Browser builds a chain to a trusted root]]
- [[Compromised root CA requires global trust store updates|Root CA compromise = global trust update]]
- [[Intermediate CA compromise only requires revoking that intermediate|Intermediate compromise: revoke just it]]

- [[X.509 certificate has TBSCertificate SignatureAlgorithm and SignatureValue|X.509: TBSCertificate, SignatureAlgorithm, SignatureValue]]
- [[TBSCertificate contains all data that gets signed|TBSCertificate holds all signed data]]
- [[Certificate version usually indicates v3 for extensions|Version field: v3 for extensions]]
- [[Serial number uniquely identifies certificate from CA|Serial number: per-CA unique ID]]
- [[Issuer DN identifies CA that signed certificate|Issuer DN identifies the signing CA]]
- [[Subject DN identifies certificate owner|Subject DN identifies the owner]]
- [[Validity period defines not-before and not-after dates|Validity: not-before / not-after dates]]
- [[Subject Public Key Info contains algorithm and key bits|SubjectPublicKeyInfo: algorithm + key bits]]

## GOST Algorithms

### Standards & Versions

- [[GOST provides Russian cryptographic independence from Western algorithms|GOST: Russian crypto independence]]
- [[GOST R 34.10 is signature algorithm using elliptic curves|GOST R 34.10: elliptic-curve signature]]
- [[GOST R 34.11 is hash function called Streebog|GOST R 34.11: Streebog hash]]
- [[GOST R 34.10-2012 supports 256-bit and 512-bit key sizes|GOST R 34.10-2012: 256/512-bit keys]]

- [[Kazakhstan uses ST RK GOST R 34.10-2015 with 512-bit keys|Kazakhstan: ST RK GOST R 34.10-2015, 512-bit]]
