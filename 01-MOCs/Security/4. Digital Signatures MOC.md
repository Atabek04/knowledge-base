Concepts for understanding digital signatures, signature formats, and XML security.
Covers signature fundamentals, CMS/PKCS#7, XMLDSig, and common security attacks.

## Digital Signature Fundamentals

- [[Digital signature proves who signed and ensures message integrity|Digital signature: proves signer + integrity]]
- [[Authenticity confirms identity of message sender|Authenticity confirms the sender]]
- [[Checksum verifies integrity but signature on checksum verifies authenticity|Checksum = integrity; signed checksum = authenticity]]
- [[Collision attack forges signatures by finding two inputs with the same hash|Collision attack: same hash forges a signature]]
- [[Integrity detects any modification to signed data|Integrity detects any modification]]
- [[Non-repudiation prevents signer from denying signature|Non-repudiation: signer can't deny]]
- [[Signing hashes message then encrypts hash with private key|Signing: hash, then encrypt hash with private key]]
- [[Hashing before signing is required because asymmetric algorithms cannot process arbitrary-length data|Hash before signing: asymmetric can't take long data]]
- [[Verification decrypts signature with public key and compares hashes|Verify: decrypt with public key, compare hashes]]

## Signature Algorithms

- [[RSA-PSS adds randomized padding for signature security|RSA-PSS adds randomized padding]]
- [[ECDSA provides efficient signatures using elliptic curves|ECDSA: efficient elliptic-curve signatures]]

## CMS/PKCS#7 Format

### Structure & Components

- [[CMS wraps data with signature and signer certificate|CMS wraps data + signature + cert]]
- [[CMS structure includes content signature algorithm and certificates|CMS: content, algorithm, certificates]]
- [[CMS signing hashes data then wraps in ASN.1 container|CMS signing: hash, then wrap in ASN.1]]
- [[SignerInfo identifies signer and holds signature value|SignerInfo: signer + signature value]]

### Signature Types

- [[Detached CMS signature stores data separately from signature|Detached CMS: data stored separately]]
- [[Attached CMS signature includes original document|Attached CMS: includes the document]]
- [[CMS supports multiple signers on same document|CMS supports multiple signers]]

## XML Digital Signatures

### XMLDSig Structure

- [[XMLDSig signs XML documents with embedded signatures|XMLDSig: embedded XML signatures]]
- [[XMLDSig handles XML structure unlike binary CMS|XMLDSig is XML-aware (unlike binary CMS)]]
- [[SignedInfo contains what was signed and how|SignedInfo: what was signed and how]]
- [[Reference element points to data being signed|Reference points to the signed data]]
- [[DigestValue holds hash of referenced data|DigestValue holds the data hash]]
- [[SignatureValue contains actual signature bytes|SignatureValue: the signature bytes]]
- [[KeyInfo embeds signer public key or certificate|KeyInfo embeds the signer's key/cert]]

### Canonicalization

- [[Canonicalization normalizes XML before signing|Canonicalization normalizes XML before signing]]
- [[C14N removes whitespace and orders attributes consistently|C14N: strip whitespace, order attributes]]
- [[Exclusive C14N includes only used namespaces|Exclusive C14N: only used namespaces]]

### Transforms

- [[Transforms apply operations before hashing|Transforms run before hashing]]
- [[Enveloped signature transform removes signature element|Enveloped transform removes the signature element]]
- [[XPath filter selects specific XML parts to sign|XPath filter selects parts to sign]]
- [[Base64 transform decodes embedded binary data|Base64 transform decodes embedded binary]]

## Security Attacks

### Attack Vectors

- [[Signature wrapping moves valid signature to different data|Signature wrapping moves a valid signature]]
- [[XXE attack exploits XML external entity loading|XXE exploits external entity loading]]
- [[XPath injection manipulates queries from unsanitized input|XPath injection via unsanitized input]]

### Defense Mechanisms

- [[Unique IDs prevent signature wrapping attacks|Unique IDs stop signature wrapping]]
- [[Disabling external entities prevents XXE attacks|Disable external entities to stop XXE]]
- [[Fixed XPath patterns avoid injection vulnerabilities|Fixed XPath patterns avoid injection]]
