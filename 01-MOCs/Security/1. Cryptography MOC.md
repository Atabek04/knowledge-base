Concepts for understanding cryptographic algorithms, key management, and data protection.
Covers fundamental cryptographic operations, symmetric and asymmetric encryption, hash functions, and key formats.

## Core Concepts

- [[Hashing produces fixed-length fingerprint that cannot be reversed|Hashing: irreversible fixed-length fingerprint]]
- [[Birthday problem explains why collision resistance requires double the security bits|Birthday problem: collision resistance needs 2× bits]]
- [[Checksum verifies integrity but signature on checksum verifies authenticity|Checksum = integrity; signed checksum = authenticity]]
- [[Preimage attack reverses hash to recover input and is prevented by salting and slow KDFs|Preimage attack reversed by salt + slow KDFs]]
- [[Collision attack forges signatures by finding two inputs with the same hash|Collision attack: two inputs, same hash, forged signature]]
- [[Encryption transforms data using key to ensure confidentiality|Encryption: reversible transform for confidentiality]]
- [[Encoding converts data format without providing secrecy|Encoding: format change, no secrecy]]
- [[Symmetric cryptography uses single key for encryption and decryption|Symmetric: one shared key both ways]]
- [[Asymmetric cryptography uses public-private key pairs|Asymmetric: public-private key pair]]
- [[Hybrid encryption uses asymmetric to exchange key then symmetric to encrypt data|Hybrid: asymmetric exchanges key, symmetric encrypts]]
- [[Cryptographic algorithms cannot encrypt arbitrary-length data for different reasons|Algorithms can't encrypt arbitrary-length data]]

## Symmetric Cryptography

### Algorithms & Ciphers

- [[AES is most widely used symmetric encryption algorithm|AES: the standard symmetric cipher]]
- [[Block cipher processes fixed-size data chunks|Block cipher processes fixed-size blocks]]

### Modes of Operation

- [[Mode of operation defines how block cipher processes long messages|Mode of operation chains blocks for long messages]]
- [[CBC mode chains blocks by XORing with previous ciphertext|CBC: XOR each block with previous ciphertext]]
- [[CTR mode converts block cipher into stream cipher using counter|CTR: counter turns block cipher into a stream]]
- [[GCM mode combines encryption with authentication tag|GCM: encryption + authentication tag]]

### Supporting Concepts

- [[IV ensures identical plaintext produces different ciphertext|IV makes identical plaintext encrypt differently]]
- [[XOR operation reversibly mixes two equal-length byte strings|XOR reversibly mixes equal-length bytes]]
- [[Keystream is generated from counter values in CTR mode|Keystream from counter values (CTR)]]
- [[Authentication tag detects tampering in GCM mode|Authentication tag detects tampering (GCM)]]
- [[MAC provides integrity and authenticity using keyed hash|MAC: integrity + authenticity via keyed hash]]
- [[HMAC creates fingerprint using hash function and secret key|HMAC: hash + secret key fingerprint]]

## Asymmetric Cryptography

### Key Pair Systems

- [[Public key encrypts while private key decrypts in asymmetric systems|Public key encrypts, private key decrypts]]
- [[RSA uses modular exponentiation with large primes for encryption|RSA: modular exponentiation over large primes]]
- [[ECDH derives shared secret using elliptic curve mathematics|ECDH derives a shared secret on elliptic curves]]

### Key Exchange

- [[Session key is short-lived symmetric key for single connection|Session key: short-lived symmetric, per connection]]
- [[Key transport encrypts session key with recipient public key|Key transport: encrypt session key with public key]]
- [[Key agreement derives shared key without transmitting it|Key agreement: derive key, never transmit it]]
- [[KDF turns shared point into uniform cryptographic keys|KDF turns a shared point into usable keys]]
- [[Ephemeral ECDH provides forward secrecy by using fresh keys|Ephemeral ECDH gives forward secrecy]]

## Key Formats & Standards

### Binary Representations

- [[Raw key consists of mathematical values without metadata|Raw key: bare math values, no metadata]]
- [[RSA public key contains modulus and exponent integers|RSA public key: modulus + exponent]]
- [[EC public key contains x y coordinates on elliptic curve|EC public key: x,y point on the curve]]
- [[Byte is eight-bit unit as smallest addressable memory storage|Byte: 8-bit smallest addressable unit]]
- [[Hexadecimal represents byte using two digits for four bits each|Hex: two digits per byte (4 bits each)]]

### Encoding Standards

- [[ASN.1 defines structure of cryptographic data types|ASN.1 defines crypto data structures]]
- [[DER provides deterministic binary encoding of ASN.1|DER: deterministic binary ASN.1 encoding]]
- [[PEM wraps Base64-encoded DER with header and footer|PEM: Base64 DER with header/footer]]
- [[Base64 converts binary to printable ASCII for text channels|Base64: binary → printable ASCII]]
- [[Tag-Length-Value structure enables unambiguous DER parsing|TLV structure enables unambiguous DER parsing]]
- [[OID uniquely identifies cryptographic algorithms and policies|OID uniquely identifies algorithms and policies]]

### Key Container Formats

- [[SPKI structure holds algorithm identifier and public key bits|SPKI: algorithm ID + public key bits]]
