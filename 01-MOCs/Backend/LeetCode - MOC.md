## Approach per Topic

1. Read Grokking module for the pattern (understand the template)
2. Attempt LeetCode problem without help (20 min max)
3. If stuck → study solution → re-implement from scratch
4. Add pattern note to this vault
5. Revisit after 3 days

**Difficulty ratio target:** 60% Medium · 30% Easy · 10% Hard

---

## Key Patterns to Internalize

- **Two Pointers:** opposite ends, slow/fast, sliding window variant
- **Binary Search:** on sorted array, on answer space, left/right boundary
- **Trees:** DFS (pre/in/post order), BFS (level order), path problems
- **Graphs:** BFS shortest path, DFS connectivity, topological sort, union-find
- **DP:** identify state, recurrence relation, base case, memoize vs tabulate
- **Backtracking:** decision tree, pruning, state restoration
