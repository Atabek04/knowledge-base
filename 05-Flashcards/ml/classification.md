Coding Questions
What is classification in machine learning?
Back: Predicting a discrete category from a fixed set of choices. **Binary** = 2 classes (spam/not spam). **Multiclass** = 3+ classes (cat/dog/bird). If the answer is "which one?" or "what type?" → classification.

Coding Questions
Why do classification models output probability scores instead of just a label?
Back: Probabilities express **confidence** (0-1) for each category. Example: "95% spam" vs "52% spam" — same label, very different confidence. Different risk levels need different thresholds (email spam filter can tolerate mistakes; cancer detection cannot).
