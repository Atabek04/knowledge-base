Coding Questions
What is design science research, and what is its contribution?
Back: Research that **designs an artifact** (system, algorithm, method) in order to **test an idea**.

- Contribution = the **knowledge from evaluating** the artifact
- Never the artifact itself
- Hevner et al. (2004); Wieringa (2014)

Coding Questions
In Wieringa's design science, why is the artifact called the "treatment"?
Back: Borrowed from medicine: the built thing is what you **treat the problem with**, like a drug treats a disease.

- The drug is not the finding; the **trial result** is
- So the artifact is not the contribution; the **evaluation** is

Coding Questions
The "bachelor trap" in design science: what is it, and what is the fix?
Back: Design science **without the science**: artifact built, **evaluation skipped**, no checkable claim.

- Passes a bachelor project (grades execution), fails a master's (grades contribution)
- Fix: decide **before building** what idea the artifact tests and what result would show it wrong

Coding Questions
The four dissertation types and what each one's contribution is?
Back:
- **Empirical**: measure the world → a **finding**
- **Theoretical**: build/extend a model, no new data → a **framework**
- **Systematic review**: synthesise all existing studies by a stated protocol → a **map of what is known**
- **Design science**: build an artifact to test an idea, evaluate it → **knowledge from the evaluation**

Coding Questions
Why does "I built an app" say nothing about a dissertation's type?
Back: Type is fixed by **contribution**, not activity. Building happens in 3 of 4 types.

- Only in **design science** is the built thing part of the method being tested
- Elsewhere it is **scaffolding** the contribution never mentions

Coding Questions
What makes a literature review "systematic", and why does an ordinary review chapter not count as one?
Back: The search is a **stated protocol** (databases, terms, inclusion criteria) another person could **rerun**.

- A review chapter inside another type has no such protocol and is not the contribution

Coding Questions
A design-science thesis's study never runs. What is the correct fallback type, and which fallback fails?
Back: Retreat **one type** to **theoretical**: defend the framework plus the protocol. Weaker, but defensible.

- The failing retreat is to **no type**: the bachelor trap, artifact described and evaluation skipped

Coding Questions
Wieringa's engineering cycle: the five tasks, and which of them form the design cycle that research does?
Back:
1. **Problem investigation**
2. **Treatment design**
3. **Treatment validation**
4. Treatment implementation
5. Implementation evaluation

Tasks 1–3 = the **design cycle** = research. 4–5 belong to **practice**, after hand-over.

Coding Questions
Wieringa: what distinguishes validation from evaluation? (Hint: not whether the artifact is released.)
Back: **Who controls the context.**

- **Validation**: researcher controls it (recruited sample, assigned conditions, fixed protocol); asks *would it work if implemented?*; buys causal isolation
- **Evaluation**: real use after transfer, nobody assigns anything; asks *what happened?*; buys realism, loses the counterfactual

Coding Questions
Startup-style "idea validation" (do people actually have this problem?) maps to which Wieringa task, and why is it not validation?
Back: **Problem investigation** (task 1).

- Wieringa's **validation** asks whether the **treatment produces the effect**, and assumes the problem is already established

Coding Questions
An app is already public. A researcher recruits 30 users, assigns conditions, and runs a 4-week protocol on it. Validation or evaluation?
Back: **Validation.** The study controls the context, so it is artificial regardless of the app being live.

- Launch = **implementation**, not evaluation
- Evaluation would observe natural adopters with no assignment
