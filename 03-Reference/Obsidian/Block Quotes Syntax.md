## Single Line

```markdown
> This is a quote
```

## Multi-line

```markdown
> Line one
> Line two
> Line three
```

## Nested Quotes

```markdown
> Level 1
>> Level 2
>>> Level 3
```

## Headings Inside Quotes

Works only in **View mode** (not Edit mode).

```markdown
> ## Heading inside quote
> Content here
```

Toggle with `Ctrl + E`.
