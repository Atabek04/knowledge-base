# Obsidian Shortcuts

## View & Mode

| Shortcut | Action |
|----------|--------|
| `Ctrl+E` | Toggle edit/read mode |
| `Ctrl+Shift+I` | Toggle sidebar (left) |
| `Ctrl+Shift+O` | Toggle sidebar (right) |
| `Ctrl+J` | Toggle preview panel |
| `Ctrl+H` | Focus left sidebar |
| `Ctrl+L` | Focus right sidebar |

## Navigation

| Shortcut | Action |
|----------|--------|
| `Ctrl+P` | Quick switcher (open note) |
| `Ctrl+O` | Quick open file |
| `Ctrl+G` | Go to line |
| `Ctrl+Tab` | Next tab |
| `Ctrl+Shift+Tab` | Previous tab |
| `Ctrl+W` | Close current tab |
| `Ctrl+K Ctrl+W` | Close all tabs |
| `Ctrl+Alt+Left` | Go back (Windows) / `Alt+Left` (Mac/Linux) |
| `Ctrl+Alt+Right` | Go forward (Windows) / `Alt+Right` (Mac/Linux) |

## Editing

| Shortcut | Action |
|----------|--------|
| `Ctrl+B` | Bold |
| `Ctrl+I` | Italic |
| `Ctrl+Shift+S` | Strikethrough |
| `Ctrl+Shift+!` | Toggle checkbox |
| `Ctrl+Shift+,` | Decrease heading level |
| `Ctrl+Shift+.` | Increase heading level |
| `Ctrl+Shift+U` | Toggle bullet list |
| `Ctrl+Shift+E` | Toggle numbered list |
| `Ctrl+]` | Indent |
| `Ctrl+[` | Unindent |

### Highlighting

| Method | Shortcut/Action |
|--------|---|
| **Manual highlight** | Type `==text==` (built-in syntax) |
| **Custom hotkey** | Settings → Hotkeys → Search "Highlight" → Assign shortcut |
| **Highlightr plugin** | Install from Community Plugins, then set up hotkeys per color |

## Link & Embed

| Shortcut | Action |
|----------|--------|
| `Ctrl+K` | Insert link |
| `Ctrl+Shift+L` | Link to note |
| `Ctrl+Shift+E` | Embed note |
| `![[` | Embed file |
| `[[` | Link to note |

## Search & Replace

| Shortcut | Action |
|----------|--------|
| `Ctrl+F` | Search in note |
| `Ctrl+H` | Find and replace |
| `Ctrl+Shift+F` | Search in vault |
| `Ctrl+Shift+H` | Replace in vault |

## Selection & Multi-Cursor

| Shortcut | Action |
|----------|--------|
| `Ctrl+A` | Select all |
| `Ctrl+L` | Select line |
| `Ctrl+D` | Select word |
| `Shift+Arrow` | Extend selection |
| `Ctrl+Shift+Arrow` | Extend selection by word |

### Multi-Cursor (Built-in)

| Shortcut | Action |
|----------|--------|
| `Alt+Click` | Add cursor at click position |
| `Shift+Alt+Drag` | Select & edit consecutive lines |
| `Escape` | Clear all cursors |

### Multi-Cursor (Requires obsidian-multi-cursor plugin)

| Shortcut | Action |
|----------|--------|
| `Alt+Ctrl+Up` | Add cursor above |
| `Alt+Ctrl+Down` | Add cursor below |
| `Alt+Shift+End` | Add cursors to end of selection lines |

## File Operations

| Shortcut | Action |
|----------|--------|
| `Ctrl+N` | New note |
| `Ctrl+Alt+N` | New note in same folder |
| `Ctrl+Delete` | Delete note |
| `Ctrl+Shift+R` | Rename note |
| `Ctrl+Shift+M` | Move note |
| `Ctrl+S` | Save (auto-saves usually) |

## Blocks & References

| Shortcut | Action |
|----------|--------|
| `^block-id` | Link to block in note |
| `[[note#block]]` | Link to specific block |
| `![[note#block]]` | Embed specific block |

## Spaced Repetition (SR Plugin)

| Shortcut | Action |
|----------|--------|
| `Ctrl+Shift+R` | Review flashcards |
| (See plugin settings) | Due card count |

## Command Palette

| Shortcut | Action |
|----------|--------|
| `Ctrl+P` | Quick switcher / command palette |
| Type command name | Search all commands |

## Backlinks & Graph

| Shortcut | Action |
|----------|--------|
| `Ctrl+Alt+G` | Open graph view |
| `Ctrl+Shift+L` | Toggle local graph |
| (Right panel) | Backlinks panel |
| (Right panel) | Unlinked mentions |

## Note Properties

| Shortcut | Action |
|----------|--------|
| (Top right) | Click book icon for properties |
| (Frontmatter) | Edit YAML properties directly |

## Useful Custom Shortcuts (Customize in Settings)

Recommended additions:
- Toggle strikethrough
- Duplicate line/selection
- Move line up/down
- Format as code block
- Paste as plaintext
