## Headings

Require space after `#`:

```markdown
# Heading 1
## Heading 2
### Heading 3
```

## Tags

No space after `#`:

```markdown
#git #flashcards #devOps
```

## Common Mistake

Typing `#word` creates a tag, not a heading.
Add space: `# word` for headings.
