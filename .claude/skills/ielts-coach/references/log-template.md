# Log template

Create `06-Planning/Trackers/IELTS-Log.md` from this if it doesn't exist. It is the coach's
only persistent state: everything that accumulates between sessions lives here, nothing in
the skill.

Keep entries append-only and dated. The value is in the trend across entries — any single
audit or mock is one noisy sample, and the recurring category is what actually drives the
next fortnight's work.
