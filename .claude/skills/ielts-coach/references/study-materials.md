skill applies here too: point at a specific unit the user owns, never at "a grammar book".

You can read a unit directly when the user asks what one covers:
`pdftotext -f <page> -l <page> -layout "<path>" -`. Murphy's unit *n* is PDF page
**`2n + 12`** — verified exact at units 1, 3, 10, 42 and 72. Each unit is two facing pages:
`2n + 12` is the explanation, `2n + 13` the exercises.

Still to buy: **Cambridge IELTS 20 and 21** — needed for the diagnostic, and the only correct
raw-score conversion tables. *Cambridge Grammar for IELTS* is **not** owned and is not
required; do not recommend it.

## Murphy — the schedule the plan runs

126 of the 145 units, **10 a week** in three weekday sittings of ~35 min, October to
December. Cover to cover does not fit; seven a week runs into the January mock month.

| Month | Units | What lands |
|---|---|---|
| **Oct** | 6–48 | Perfect aspect, perfect vs past, past perfect, future, modals, conditionals & *wish*, passive, reported speech |
| **Nov** | 53–97 | *-ing and to…*, countability, **articles (72–76)**, determiners, **relative clauses (92–96)**, *-ing/-ed* clauses |
| **Dec** | 98–136 | Adjectives & adverbs, comparatives, word order, *although/unless/as long as*, all prepositions |
| **Dec, last week** | Study Guide p. 326 | Maps wrong answers to unit numbers — redo only what it flags |
| **Jan, Feb** | — | Nothing new. January is mocks, February is reviews |

**Skipped, and why** — 1–5 already the working inventory · 49–52 questions and tags,
Speaking-only · 77–78 names with/without *the* · 137–145 phrasal verbs, wrong register for
Task 2. Prepositions 121–128 were cut at the old 6 h/week budget and are back in at 12.

The **grammar Anki deck already exists for all 145 units**, and a block is unsuspended only
after that block has been read — never ahead of it. If the user asks whether to card a unit
early, the answer is no: a card tests knowledge, it does not deliver it.

Units worth naming by number in an audit, because they answer the commonest findings:

- **68** *-ing clauses* — the participle clause that keeps showing as absent in the range inventory
- **72–76** the article block — the dominant error category for this writer
- **92–96** relative clauses · **97** *-ing* and *-ed* clauses
- **42–46** the passive, including reporting passives
- **38–41** conditionals and *wish*
- **7–16** perfect aspect — the structure Task 1 trend description needs

If a month runs short, units are **dropped**, not the rate halved. Say so when the user
proposes catching up at three a week.

**English Vocabulary in Use Advanced stays shut this cycle** — C1/C2 lexis on a three-tense
grammar base produces the rare-word-in-the-wrong-slot error that Lexical Resource scores as
an inaccuracy while buying no range. Only if January runs ahead: units 80 (Academic writing:
text structure), 81 (Writing: style and format), 70 (Modality), 71 (Number: statistics).

## How to use this in each mode

**audit** — the two study targets that close a Writing audit must be unit numbers from the
tables above, not topic names. "Articles: generic reference and zero article with
uncountables — Murphy 72–76, and 69–71 for the countability half" is usable; "work on
articles" is not.

**drill** — if the fault is a grammar structure, the drill is that Murphy unit's exercises
plus one essay paragraph using the structure. Exercises alone do not transfer.

**Anything the user has not reached yet** — say so and give the unit number anyway, marked
as ahead of schedule. Knowing the fix exists at unit 68 is worth more than a vague promise
that participle clauses come later.

## Practice tests

**IELTS Mock Lab** (`ieltsmocklab.com`) — Cambridge **11–20**, four full tests each, on a
computer-delivered interface, no signup. Listening: 40 full tests, none from Book 10.
Reading: 41, including one from Book 10. Both hubs have a **Full Tests** tab and a **Single
Passage** tab, so a single section or passage can be sat on its own — that is what the
October–November drilling uses.

**Books 19 and 20 are reserved for the January mocks.** Never suggest one before January.
Auto-grade with **IELTSFreeTests** (official raw→band conversion); Mock Lab's own band
estimate is a rough banding, not a conversion table.

Which test falls on which day is fixed in `../Ribaat/06-Planning/Topics/IELTS/IELTS-Test-Calendar.md` —
read it before proposing practice, and name the scheduled test rather than inventing one.

`../Ribaat/06-Planning/Topics/IELTS/IELTS - Prep Plan.md` (Ribaat vault, sibling of this one). The budget is **~12 h/week** — 1 h each weekday,
3–4 h each weekend day — not the 6 h an earlier draft assumed.
